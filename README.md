# Segundo Cérebro com IA: Arquitetura Limpa & Clean Code 🧠⚡

Este repositório documenta a criação e interação com um **Especialista em Arquitetura Limpa (Clean Architecture)** construído através do **Gemini Notebook** (antigo *NotebookLM*). O objetivo deste projeto é demonstrar o uso de Inteligência Artificial para curadoria, estudo estruturado e extração de conhecimento fundamentado exclusivamente em fontes selecionadas de alta autoridade.

---

## 📌 Tema e Objetivo

**Frase do Objetivo:**
> *"Construir um especialista em Arquitetura de Software e Clean Code capaz de sintetizar padrões de projeto, orientar o desacoplamento de código e fornecer boas práticas de desenvolvimento web escalável a partir de fontes técnicas selecionadas."*

---

## 📚 Fontes Selecionadas e Justificativa de Confiança

Para evitar o acúmulo de informações sem critério (*"lixo entra, lixo sai"*), foram selecionadas três fontes complementares em formatos e abordagens distintas:

1. **Vídeo no YouTube:** [Arquitetura Limpa na Prática](https://www.youtube.com/watch?v=zcDKQqFmjEA)
   * **Justificativa:** Demonstração prática do fluxo de dados e aplicação real dos conceitos em cenários de desenvolvimento de software moderno.
2. **Artigo Acadêmico/Técnico:** [Engenharia de Software Moderna - Arquitetura Limpa](https://engsoftmoderna.info/artigos/arquitetura-limpa.html)
   * **Justificativa:** Material didático e rigoroso do Prof. Marco Tulio Valente (UFMG), fornecendo embasamento teórico sólido sobre desacoplamento e limites arquiteturais.
3. **Artigo Corporativo de Engenharia:** [Clean Architecture: A Arquitetura Limpa](https://zup.com.br/blog/clean-architecture-arquitetura-limpa/)
   * **Justificativa:** Visão de mercado e de larga escala da Zup Innovation sobre como implementar a arquitetura em times de alta performance.

---

## 🤖 Diretriz de Comportamento (System Prompt)

Para garantir respostas focadas e com tom técnico adequado, o assistente recebeu a seguinte instrução:

> *"Comporte-se como um Arquiteto de Software Sênior especialista em Clean Code, princípios SOLID e desacoplamento de sistemas web. Suas respostas devem ser estritamente baseadas nas fontes fornecidas, priorizando a manutenibilidade, a clareza conceitual e a escalabilidade de código."*
